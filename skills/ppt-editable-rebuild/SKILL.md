# 将图片演示文稿重建为可编辑 PPT

本技能首版为 Codex 工作流测试版。制作员需要按页面规格编写制作逻辑，使用当前环境中获授权的 `@oai/artifact-tool`。本包没有完整自动转换程序，也没有附带该运行库。每个使用环境均需验证依赖和真实样页。

## 开始前确认材料与能力

先读 [生产流程](references/workflow.md) 和 [验收证据](references/evidence.md)。确认源文件、目标页、权威文字、素材使用范围、输出位置和成功标准。源图决定布局；经确认的脚本决定文字和数字。两者冲突时停在材料确认阶段。

从 Codex 的工作区依赖工具和当前演示文稿文档定位运行库。只读取公开或随环境提供的 API 文档，通过支持的导入与导出接口验证能力。禁止阅读运行库内部实现、复制私有运行库、将其打入发布包，或从公共包名自动安装同名库。需要新增依赖或取得授权时，先由使用者确认来源和许可。许可证未知或不允许目标用途时，停止该生产步骤。

模块二的交接包按 [生产流程中的交接核对](references/workflow.md#核对模块二交接包) 逐项验证。用户已有图片 PPT、PDF 或逐页图可独立进入本技能，按同样要求冻结来源和页码。

先检查 Node.js、获授权的 artifact-tool 和所需字体。再验证图片查看、七个独立角色和 PowerPoint 操作。创建、保存并重新导入一个最小能力测试文件。测试文件与用户成果分开保存。缺少核心能力时明确报告“当前未接入”并停止相应生产步骤。引擎固定为 artifact-tool；切换工具需要重新确定任务方案。

## 按七个独立角色执行

| 角色 | 职责与产出 |
| --- | --- |
| 总调度 | 冻结输入、哈希、页码映射、工具版本与执行记录。 |
| 页面分析员 | 识别画布、布局、阅读顺序、语义和不确定文字。 |
| 元素拆解员 | 编制逐页对象规格，登记坐标、样式、层级和对象类型。 |
| 素材处理员 | 提取获准素材、导出真实库图标并登记来源与许可。 |
| PPT 制作员 | 使用实际 artifact-tool API 创建、保存、重新导入并渲染 PPTX。 |
| 视觉对比员 | 查看完整源页和候选渲染，独立评分并提交具体差异。 |
| 最终验收员 | 核对所有目标页、文件身份、原生性和实机证据，决定通过或返修。 |

七个角色分别由独立的真实智能体执行。记录各自的执行标识、输入输出和时间。并发槽位有限时分阶段串行；保留七个独立执行者。一个智能体改名、换提示词或重写报告不能充当多个独立角色。制作员不得代替视觉对比员或最终验收员签发通过结论。

先完成代表样页并取得用户认可，再按 3 至 5 页推进。每次修改或合并后，重新绑定当前候选哈希与审核证据。角色调度细节和验收条件见参考文档。

## 保留原图并重建普通对象

普通文字、卡片、模块框、表格、图例、线和箭头使用原生对象。表格保持单元格可编辑，文字保持独立文本，箭头保留方向与连接关系。按实际字体校准换行、行距和内边距。

原界面、照片、生成插画和获准复杂示意保留为独立图片。优先复用真实原文件；只有整页图时，记录提取区域与来源。普通流程、表格和文字不得整块栅格化。图标优先使用真实图标库，登记库名、来源、许可和文件哈希。素材不足时报告缺项，近似生成图不能冒充原素材。

## 按证据验收当前候选

每页视觉评分至少 90 分。90 至 94 分逐项写明差异和影响。文字数字错误、重要内容缺失、关系方向错误、普通对象不可编辑、角色不独立或实机验证失败均阻断交付。平均分不能抵消失败页。

最终文件需要在真实 PowerPoint 中打开且没有修复提示。检查完整页面与主要对象，在独立验证副本中修改原有文字和表格单元格，保存、关闭并重开。确认修改保留、布局正常。无表格的任务记录“不适用”及原因。缺少 PowerPoint 或文件授权时停在待审核状态。

结构检查助手使用 Python 3.10 或更新版本，只依赖标准库：

```sh
python3 scripts/ooxml_check.py candidate.pptx --source source.pdf --json-out reports/structure.json
python3 -m unittest discover -s tests -v
```

命令相对于本技能目录执行。输入和输出路径由当前任务提供。检查报告绑定输入及候选 SHA-256；结构结果、视觉结论、独立角色和实机结果分别记录。该脚本不生成 PPT，也不签发最终验收。参数、限制和退出码见 [验收证据](references/evidence.md)。

最终交付包括可编辑 PPTX、逐页预览、逐页规格、独立素材与清单，以及绑定文件哈希的验收报告。尚未完成全部条件时，文件保持候选稿或待审核状态。保留原始资料；覆盖、删除和对外发送需要相应授权。
